R-012026

MedTokenBudget：面向皮肤镜图像分类的病灶保留 Token 路由

独立作者 · arXiv 预印本

用更少的图像 Token，保留病灶证据。

细节 +

在冻结的视觉骨干网络之后做病灶监督的 Token 路由。ISIC 2019、30% Token 预算下，三个随机种子的准确率为 80.38 ± 0.18%，ToMe 为 76.93 ± 0.03%；骨干网络保持不变。

arXiv:2609.30613 ↗

↗
R-022026

Mass-Conservation Token Transformers：可审计的串联质谱检索

已投稿 AAAI 2027

用质量守恒关系，为质谱检索提供可检查的证据。

细节 +

把满足质量守恒关系的碎片对编码为稀疏证据 Token，并构建质量接近与谱峰重叠的难负样本。通过移除证据前后排序的变化，检验导出的证据是否真的参与了判断。

↗
R-032025

Efficient Attention via Pre-Scoring

第一作者 · 审稿中

在注意力计算之前，先筛选信息量更高的键区间。

细节 +

在 CMU David P. Woodruff 教授指导下完成。用 Triton 实现预评分与关键键筛选，与 HyperAttention 结合后，在固定交互预算、131k token 上下文的 ChatGLM 实验中把困惑度从 12.0 降到 9.5。这不是实测加速比。

arXiv:2505.11040 ↗

↗
R-042026

面向抗病毒药物发现的机器学习

USC · Yan Liu 课题组 · 2026 春

可复现的分子基准与模型解释。

细节 +

在七个 Therapeutics Data Commons 数据集上，用分子骨架划分比较描述符模型、Chemprop 与混合模型；结合描述符重要性与 SHAP 归因，考察与抗病毒活性预测相关的分子特征。
